# Trust Ledger — EDITOR-3 타입별 상한

- 작성일: 2026-08-12
- 모드: 핵심(core) / 표준 프로파일

## 긴급 감사 (H1~H4)

순수 값 타입, I/O 없음. 초점은 **"두 판정이 어긋날 수 있는가"** 와
**"사용자 작업물을 임의로 버리는가"** 둘이다.

### [HIGH → 방지] 분류가 두 벌로 갈라질 뻔했다

타입 → 범주 매핑(`text`·`shape`·`stamp`가 **합산**된다)이 `validate()` 안의
`switch`에만 있었다. 스토어가 삽입을 막으려고 같은 `switch`를 다시 쓰면 두 벌이
되고, **한쪽만 바뀌면 삽입은 막히는데 저장은 통과한다**(또는 반대).

- 방어: `LayerCategory`(분류 + 상한)를 한 곳에 두고 `Layer.category`로 노출.
  `validate()`와 `LayerStore`가 **둘 다 그것을 쓴다**. `LayoutDocument.photoLimit`
  등 기존 상수는 값을 복제하지 않고 `LayerCategory`를 되짚는 별칭으로 바꿨다
- 검증: `각_타입이_상한을_꽉_채운_문서는_통과한다` — 스토어 상한까지 정확히
  채운 레이어로 문서를 만들어 `validate()`가 통과하는지 본다. **두 경계가
  같다는 것을 행위로 묶는다**
- 변이 B(`stamp`를 `decor`에서 빼기)·I(`validate`가 `>=` 비교)가 각각 4건·3건에
  잡혔다

`EDITOR-1`에서 `workArea`를 공개해 `EDITOR-9`가 다시 정의하지 못하게 한 것과
같은 자리다. **이 저장소에서 세 번째로 나온 패턴이다.**

### [MEDIUM → 방지] 상한 초과 문서를 잘라낼 뻔했다

다른 버전이 만들었거나 손상된 문서는 상한을 넘긴 채로 들어올 수 있다.
`init`에서 자르면 **사용자의 작업물이 조용히 사라진다** — 이 저장소의 첫 번째
약속("작업물이 절대 증발하지 않는다")을 정면으로 어긴다.

- 방어: 불러오기는 그대로 담고, **더 넣는 것만** 막는다. `remaining`은
  `max(0, ...)`이라 음수가 되지 않는다
- 검증: `상한을_넘긴_문서를_불러와도_잘라내지_않는다`(변이 H가 4건에 잡힘),
  `이미_넘긴_상태에서_남은_개수는_음수가_아니다`(변이 E가 잡음)

### [설계] 거부는 던진다

`PromotionError`·`RepositoryError`와 같은 규칙 — 실패는 맥락을 들고 던진다.
조용히 `nil`을 돌려주면 호출부가 무시할 수 있고, **사용자가 넣었다고 생각한
레이어가 없는 채로 진행된다.**

`LayerLimitError.limitReached(category:limit:)`가 범주와 상한을 들고 있어
호출부가 "사진은 8장까지 넣을 수 있어요"를 만든다(v4 §5.13).

정상 흐름에서는 도구 버튼이 이미 비활성이므로(`canInsert`) 던지는 일 자체가
드물다 — **던진다는 것은 배선이 판정을 안 썼다는 신호다.**

## 위험 수용

- [복제 경로 미검증] v4 §5.12.1의 "복제본도 `photo` 상한 8개에 포함된다"는
  복제가 `insert`를 타므로 자동으로 걸린다. 다만 **복제 자체가 아직 없어**
  (`TOOL-3`) 그 경로로는 검증하지 못했다. `TOOL-3`에서 확인할 것
- [안내 문구 없음] 에러가 범주와 상한을 들고 있을 뿐, 문구는 배선
  (`EDITOR-11`)이 만든다. 문구가 상한 숫자를 하드코딩하면 다시 두 벌이 되므로
  **반드시 `category.limit`을 읽어야 한다**
- [`insert` 시그니처 변경] `EDITOR-2`에서 넣은 `insert`가 이제 `throws`다.
  호출부가 아직 테스트뿐이라 파급이 없었다
- [상한 초과 문서의 저장] 12장짜리 문서를 열어 그대로 저장하면 `validate()`가
  거부한다(`CanvasPromoter` 1단계). **사용자는 열 수는 있는데 저장은 못 하는
  상태가 된다.** 지금은 그런 문서를 만들 경로가 없지만(우리 앱만이 문서를
  만든다), 버전 간 이동이 생기면 `CANVAS-6`에서 다뤄야 한다
