# Trust Ledger — EDITOR-10 (제스처 라우팅 + 클램프 게이트)

## 이 단위가 갚은 것과 갚지 못한 것

**갚은 것**: `clampedLayerCenter` 호출 강제 게이트 — **6번 연속 이월 종료.** 수단은 플레이스홀더 테스트가 아니라 **타입**이었다(`ClampedLayerCenter` 토큰 + 세 계층 이동 API + 세터 셋 `internal(set)`).

**6번 이월된 진짜 원인**(이번에 드러남): 지금까지 강제할 자리를 `clampedLayerCenter` 근처에서 찾았는데, 실제 문지기 자리는 **아직 존재하지 않던 `LayerStore`의 mutating 함수**였다. `LayerStore`의 public mutating 8개 중 중심을 바꾸는 것이 하나도 없었으므로 **막을 대상 자체가 없었다.** 그래서 매번 "다음 단위에서"로 밀렸다.

**갚지 못한 것**: 닫힌 것은 **5개 경로 중 이동 축 하나**다. 상세는 `context/editor/architecture.md`의 5행 표.

### 부채 회계 (사용자 확정 — product-owner가 올린 제품 결정)

인수 검증에서 product-owner가 **FR-5를 부분 충족**으로 판정하고 회계 방침을 제품 결정으로 올렸다. 사용자 확정: **원래 부채 종료 + 신규 제약 4건 분리.**

### [GAP/HIGH] `LayoutDocument` 캔버스 디코딩 무검증 — **이 단위가 도달 가능하게 만든 이월 결함**

- 근거: `LayoutDocument.swift:166-168`의 `init(from:)`이 `canvas.w`/`h`를 `isFinite`·`> 0` 검사 없이 디코딩한다. `Size2`(`Vec2.swift:20-33`)도 검증이 없다. **오케스트레이터가 코드로 직접 확인함.**
- **NaN 경로는 아니다** — JSON 표준에 NaN 리터럴이 없고 저장소에 `nonConformingFloatDecodingStrategy` 설정이 0건(감사자 grep 확인). 그러나 `w=0` · `w<0` · 거대값은 **100% 도달 가능한 유효 JSON**이다.

- 권고: **`EDITOR-11`의 선행 차단 조건으로 명문화.** 배선과 무관하게 지금도 고칠 수 있다.

## 이월 (수신자 명시)

1. **`SoozipLayout` 모듈 내부 우회** → `EDITOR-11`. `LayerStore.place`는 **봉쇄가 아니라 선점**이다 — `storage`가 `private`이라 같은 파일 안에서 `storage[i].layer.transform.x = …`가 그대로 컴파일된다. 검증 수단 없음(코드 리뷰뿐).
2. **`LayoutDocument` 캔버스 무검증 디코딩** → `SoozipLayout`/`EDITOR-11`. **심각도가 이 단위 때문에 올라갔다** — `EDITOR-9`는 "호출부 0건이라 도달 불가"로 이월했는데, 이 단위가 게이트 통과를 강제하면서 `{"w": 0}` 문서의 x 붕괴가 **실제 경로**가 됐다. **`EDITOR-11` 배선 착수 전에 닫아야 한다.**
3. **`workArea` 2줄 재기술** → `EDITOR-11`. `public`이라(경계를 그려야 하므로) `min(max(p.x, s.workArea.min.x), …)`가 언제나 가능하고 **그 2줄에는 비유한 가드가 없다.** 미리 잘려 `1620`이 된 `∞`를 토큰에 넣으면 `isFinite` 가드가 발동하지 않아 AC-17 계약이 **공개 표면만으로** 깨진다. 방어는 `CanvasSurface.swift`의 경고문뿐.
4. **토큰 위조** → 구조적으로 닫을 수 없음. `CanvasSurface.init`이 `canvas`를 검증하지 않아 `canvas: Size2(1e9, 1e9)` 표면 한 줄로 `(99999, 99999)` 토큰이 나온다. 토큰이 증언하는 것은 "인자로 준 표면에 대해 잘렸다"뿐.
5. **구성 축(`init`)** → 닫을 수 없음. `LayerFrame.init`·`LayerTransform.init`·`Layer.transform` 통째 대입이 모듈 밖에서도 열려 있다. 실질 억제는 하나뿐 — `LayerTransform.init`이 나머지 4필드를 기본값으로 **리셋**하므로 `placed(at:)`가 유일하게 보존하는 경로다.
6. **크기 축(`scale`)** → `EDITOR-11`. 리사이즈 저장 경로가 생기면 중심은 `x`/`y`(닫힘)를 지나지만 크기는 `scale`(열림)을 지난다. **리사이즈 저장 경로의 절반에는 게이트가 없다.**
7. **`ResizeAnchor` 무클램프 중간값** → `EDITOR-11`. 오늘 저장 상태가 될 수 없는 이유는 **게이트가 막아서가 아니라 `LayerFrame → LayerTransform` 역변환이 없어서**다. 역변환을 만드는 날 이 근거는 사라진다. 고정점 유지 vs 클램프 충돌은 **정책 결정**이다(v4 §5.7 ↔ §5.10).
8. **`ended()`에 주인이 없다** → `EDITOR-11`(`ExclusiveGesture`). 이 상태 기계가 막는 것은 **동시 시작**이지 **해제 후 즉시 재잠금**이 아니다. 두 인식기가 동시에 살아 있으면 먼저 끝난 쪽의 `onEnded`가 잠금을 풀고 살아 있는 쪽이 다른 라우트로 즉시 재잠금한다 — §13 순간이동 재현.
9. **`hasSelection: Bool` 반전** → `EDITOR-11` 통합 축. 반대로 넘기는 배선은 이 단위의 테스트 15건을 **전부 통과**한다. 인자 라벨이 유일한 방어.
10. **BR-7 자동 관측 부재** → 이월 권고(test-architect). `scripts/test.sh`에 공개 표면 회귀 가드 한 줄(`rg -q 'public var center|public var x: Double'`)을 넣으면 가시성 회귀가 셸 게이트로 잡힌다. **사용자가 이번 단위 포함을 선택하지 않아 권고로만 남긴다.**

1. **`private(set)`이면 충분하다고 측정했으나 틀렸다.** `.center = ` 패턴만 grep해서 `ResizeAnchor.swift:148-149`의 부분 대입(`result.center.x += …`)을 놓쳤다. architect가 반박했고 재확인 결과 architect가 옳았다 — `internal(set)`이 맞다.
