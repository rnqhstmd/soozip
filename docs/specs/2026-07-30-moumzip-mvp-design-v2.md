# 「모음 집(Moeum Zip)」 iOS MVP 설계 문서 v2

> 2026-07-30 확정. v1(`2026-07-29-moumzip-mvp-design.md`)을 대체한다.
> v1 대비 변경: **2탭 구조(홈/내 정보), 사진 우선 생성 플로우, 도감을 내 정보로 이동,
> 재편집 P0 승격, Undo 추가, 로컬 알림 4종, 저장 완료 모먼트, 백업 내보내기, 앱스토어 요건 반영.**
> 데이터 모델·지도 렌더링·익스포트 파이프라인은 v1 그대로 유효하다.

## 1. 앱 개요

- **앱 이름:** 모음 집 (Moeum Zip)
- **컨셉:** 서울 25개 구 단위로 하루의 조각을 수집하는 디지털 콜렉트북. 아날로그 질감, 지도 색칠 게이미피케이션
- **플랫폼:** iOS 17+ (빌드는 Xcode 26/iOS 26 SDK), SwiftUI, SwiftData + CloudKit. 서버·계정 없음
- **UX 원칙:** ①지도가 목차다(지도=내비게이션이자 필터) ②사진이 먼저다(생성은 콘텐츠에서 시작) ③감정 피크(저장 직후)에 성취·공유·권한을 겹친다

## 2. 정보 구조 — 2탭

```
탭1 「홈」
 ├─ 지도 헤더: 서울 25구, 방문 심도 6단계 색칠
 │   · 구 탭 → 아래 그리드가 해당 구로 필터 (다시 탭 → 해제)
 │   · 스크롤 다운 시 얇은 정복률 바(n/25)로 접힘 (축소 헤더)
 ├─ 페이지 그리드: 기본 전체 최신순
 │   · 헤더: 정렬(최신/오래된) · 날짜 필터 칩 · 검색 아이콘(제목 인라인 검색)
 │   · 탭 → 전체화면 뷰어 (스와이프 / 공유 / 재편집 / 메타 수정 / 삭제)
 └─ 플로팅 [+] → 사진 우선 생성 플로우

탭2 「내 정보」
 ├─ 통계 카드: 총 페이지 · 정복 구 n/25 · 이번 달 기록 · 연속 기록(스트릭)
 ├─ 성취: 도감(구 카드 25장, 미방문 실루엣·대표 썸네일) · 가장 진한 구 Top3
 └─ 설정
     ├ 알림   리마인더 토글·요일/시간, 이어서 작성·추억·월간 결산 토글
     ├ 보안   Face ID 잠금
     ├ 데이터 iCloud 동기화 상태·사용 용량, 백업 내보내기/가져오기(zip), 캐시 정리
     └ 정보   지도 데이터 출처(공공누리)·폰트 라이선스·오픈소스,
              개인정보 처리방침, 문의(mailto), 앱 평가(SKStoreReviewController), 버전
```

- 별도 '모음' 탭 없음 — 홈 그리드가 전체 아카이브를 겸한다 (같은 데이터의 이중 노출 방지)
- 도감은 홈 토글이 아니라 내 정보의 성취 섹션에서 진입 (홈은 지도+그리드로 단순 유지)
- 성취 3중 구조 유지, 배치만 재분배: 심도 색칠(홈 지도) / 정복률 바(축소 헤더) / 도감(내 정보)

## 3. 생성 플로우 — 사진 우선

```
[+] → PHPicker (최대 8장 일괄 선택, 권한 불필요)
    → 에디터 (자동 흩뿌리기 배치: 랜덤 미세 회전 -3°~3°)
    → [완료] → 저장 시트: 구 확정(최근 구 프리셀렉트=1탭) · 제목 · 날짜
    → 저장 완료 화면: 해당 구가 진해지는 미니 지도 연출 + 공유 CTA
    → (첫 저장 시 1회) 알림 프리프롬프트 → 시스템 권한 다이얼로그
    → 홈 복귀 (지도 갱신 확인)
```

- 구 선택을 저장 시점으로 이동 — 진입 게이트 제거, 백지 공포 제거
- P1: 사진 EXIF 위치로 구 자동 제안 (유저 위치 추적 없음. PHPicker가 EXIF 위치를 유지하는지 스파이크 확인)

## 4. 에디터

- **캔버스:** 논리 좌표 1080×1920 고정 (기기 무관 동일 재현, 익스포트=스케일 1.0)
- **도구바:** 사진 추가 · 텍스트 · 날짜 도장 · 펜 · 배경
- **레이어 4종 통일 구조** (렌더러만 타입별, 선택·변형·z-order 공유):
  - photo / text(폰트 4~5종·크기·색) / stamp(=텍스트 프리셋) / drawing(=PencilKit을 이미지로 베이크)
- **조작:** 단일 선택. 탭 선택/빈 곳 해제. 선택 레이어만 이동·핀치·회전, 우하단 코너 핸들(크기+회전), 선택 시 삭제·앞으로·뒤로
  - 회전 레이어 드래그엔 역회전 행렬 적용 필수 (스파이크 S2)
- **Undo:** 펜 모드 내 undo/redo · 레이어 삭제 시 스낵바 "실행 취소" · 뒤로가기 시 변경 파기 확인
- **자동 임시저장:** 변경 1.5초 디바운스 → layoutJSON 갱신. 재실행 시 "이어서 할까요?"
- **햅틱:** 도장 찍기, 레이어 스냅, 저장 완료
- **재편집 (P0):** 뷰어 → 편집 → 같은 에디터에 layoutJSON 로드 → 저장 시 renderedPNG 재생성

## 5. 데이터 모델 (v1 그대로 — 되돌릴 수 없는 확정)

CloudKit은 출시 후 additive-only. 아래 3가지는 첫 심사 전 확정.

1. 레이어는 `layoutJSON` 한 덩어리 (부분 동기화 차단, 내부 스키마 자유 진화)
2. 논리 좌표 1080×1920
3. `regionCode` 10자리 법정동코드 — 구 단위는 뒤 5자리 `00000` (성동구 `1120000000`), 후일 동 확장 시 마이그레이션 0

```swift
@Model final class Page {
    var id: UUID = UUID()
    var regionCode: String = ""
    var title: String = ""
    var createdAt: Date = Date()
    var layoutJSON: Data = Data()
    var photos: [PagePhoto]? = []
    @Attribute(.externalStorage) var renderedPNG: Data?   // 캐시. 재편집 시 재생성
}
@Model final class PagePhoto {
    var id: UUID = UUID()
    @Attribute(.externalStorage) var data: Data = Data()  // 2000px 사본 → CKAsset
    var page: Page?
}
```

- SwiftData+CloudKit 제약: 전 속성 기본값/optional, `@Attribute(.unique)` 불가, 관계는 양방향 optional
- iCloud 미로그인/용량 초과 → 로컬 모드 자동 격하 + 설정에 상태 배너

### 레이어 JSON 스키마 (v1)

## 6. 지도

- 서울 25구 GeoJSON → 정규화 좌표(0~1) SwiftUI Path 사전 변환. 탭 히트테스트 `Path.contains(_:)`
- 심도 6상태: 미방문(회색) / 1~2 / 3~4 / 5~9 / 10~19 / 20+
- 축소 헤더: 스크롤에 따라 지도 ↔ 정복률 바(n/25) 전환
- 경계 데이터 라이선스(공공누리) 확인 + 설정>정보에 출처 표기

## 7. 익스포트

```
논리 캔버스 1080×1920 → ImageRenderer(scale:1.0) → JPEG 0.9 → iOS 공유 시트
                          └─ [오버레이 슬롯: 비어있음] ← P1 비닐 자리
```

워터마크 없음. 갤러리 저장은 공유 시트 경유 (`NSPhotoLibraryAddUsageDescription` 필요).

## 8. 로컬 알림 (서버 없음 — 전부 UNUserNotificationCenter)

| 알림 | 트리거 | 기본값 |
|---|---|---|
| 기록 리마인더 | 사용자 지정 요일·시간 | off |
| 이어서 작성 | 임시저장 24시간 방치 시 1회 | on |
| 추억 소환 | "1년 전 오늘 ○○구에서" (해당 날짜 페이지 존재 시) | on |
| 월간 결산 | 매월 말 "이번 달 N개 구 수집" | on |

- 권한 요청: 첫 페이지 저장 완료 직후 프리프롬프트 → 시스템 다이얼로그. 온보딩·첫 실행에서 묻지 않음
- 알림 인박스 없음 (iOS 알림 센터로 충분). 설정>알림에서 종류별 토글
- 앱 기능이 알림 허용에 의존하지 않을 것 (심사 4.5.4)

## 9. 첫 실행

- 온보딩 화면 없음. 빈 지도(전부 회색) + 그리드에 **고스트 예시 페이지 1장** (탭하면 사라짐, "첫 페이지를 만들어보세요")
- 심사자가 처음 보는 화면이므로 빈 상태가 의도된 디자인으로 보여야 함 (2.1 완성도)

## 12. 앱스토어 요건 (필수)

1. Xcode 26 / iOS 26 SDK 빌드 (2026-04-28부터 강제)
2. 개인정보 처리방침 URL + 지원 URL
3. App Privacy 라벨 — "데이터 수집 안 함" 선언
4. PrivacyInfo.xcprivacy (required-reason API 사유)
5. Info.plist: `NSPhotoLibraryAddUsageDescription`, `NSFaceIDUsageDescription`
6. `ITSAppUsesNonExemptEncryption = NO`
7. CloudKit 프로덕션 스키마 배포 (심사 전, 이후 additive-only)
8. 라이선스 고지 (공공누리 출처, 폰트 OFL) — 설정>정보
9. 연령 등급·스크린샷·메타데이터 일치, 심사 노트 "계정·서버 없음"
10. `UIUserInterfaceStyle = Light` 고정 (다크모드 미지원)
- 면제: 계정 삭제(계정 없음)·ATT(추적 없음)·UGC 신고(앱 내 노출 없음)
- EU 배포 시 DSA trader 선언 필요 → 개인 무료 앱은 non-trader 선언 또는 배포 지역 한정

## 13. 테스트

- 레이어 JSON 인코딩→디코딩 라운드트립 (v1 호환 회귀)
- 회전 상태 드래그 좌표 변환 단위 테스트
- 익스포트 결과 크기·비어있지 않음 검증
- 재편집: 저장→로드→재저장 시 레이아웃 불변 검증
- CloudKit 동기화: 실기기 2대 수동 검증

## 14. 구현 순서 (P0)

**스파이크 먼저:**

| # | 항목 | 검증 내용 |
|---|---|---|
| S1 | 익스포트 | blendMode 오버레이 포함 뷰가 ImageRenderer에 살아남는가 |
| S2 | 제스처 | 회전 레이어 드래그 방향 (역회전 행렬) |
| S3 | SwiftData+CloudKit | 기본값 제약 모델 실기기 2대 동기화 |
| S4 | 지도 | GeoJSON→Path 변환 + 탭 히트테스트 + 축소 헤더 |
| S5 | (P1 대비) PHPicker EXIF | 위치 메타데이터 유지 여부 |

이후: 데이터 레이어 → 에디터(재편집 포함, 공수 40%) → 홈(지도+그리드) → 저장 완료·공유 → 내 정보·설정·알림 → 잠금·백업

## 15. 우선순위 정리

- **P0:** 위 전부 (재편집 포함)
- **P0.5:** 백업 내보내기/가져오기 (레이어 JSON+사진 zip → Files 앱)
- **P1:** EXIF 구 자동 제안, 마스킹테이프, 비닐 오버레이·바인더 링·사운드(오버레이 슬롯 확보됨), 동(洞) 단위 확장
- **제외:** 위젯, 다크모드, GPS 추적, 온보딩 화면, 수익화, 서버·계정

## 16. 남은 리스크

1. GeoJSON 라이선스 — 공공누리 유형 확인
2. 폰트 라이선스 — 임베딩 가능 여부, 종별 원문 확인 (Figma 작업 전 확정)
3. CloudKit 스키마 — 첫 심사 전 모델 동결
4. 지도 축소 헤더 + 그리드 스크롤 성능 (썸네일 캐시 필수)
