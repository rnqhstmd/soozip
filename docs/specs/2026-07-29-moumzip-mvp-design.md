## 1. 앱 개요

- **앱 이름:** 모음 집 (Moeum Zip)
- **컨셉:** 서울 구(區) 단위로 하루의 조각을 수집하는 디지털 콜렉트북 (아날로그 질감, 지도 색칠 게이미피케이션)
- **플랫폼:** iOS 17+, SwiftUI, SwiftData + CloudKit (서버리스·계정 없음)

## 2. 확정 결정 (전 라운드 종합)

| 영역 | 결정 |

## 3. 화면 구조 (당시 결정 — 단일 홈)

```
홈 (단일 화면)
├─ 상단: [지도 | 도감] 세그먼트 토글
│   ├─ 지도  — 서울 25구, 심도 6단계 색칠, 구 탭 → 해당 구 페이지만 필터
│   └─ 도감  — 구 카드 25장, 미방문은 실루엣, 대표 사진 썸네일
├─ 중단: 검색바 (구/날짜/제목)
├─ 하단: 페이지 그리드 → 탭하면 전체화면 스와이프 뷰어
├─ 우하단 [+] → 구 선택 시트 → 에디터
└─ 우상단 ⚙ → 설정 (Face ID 잠금 / iCloud 동기화 상태 / 사용 용량)
```

> 2026-07-30 보고에서 알림·내 정보 추가에 따라 3탭 구조로 변경 제안됨.

## 4. 데이터 모델 (되돌릴 수 없는 결정)

CloudKit은 출시 후 스키마가 additive-only이므로 아래 3가지는 첫 출시 전 확정 필수.

1. **레이어는 JSON 한 덩어리(`layoutJSON`)로 저장** — CloudKit 부분 동기화 문제 차단, 스키마 자유 진화, P1 재편집 대비
2. **논리 좌표 1080×1920 고정** — 기기 간 동일 재현, 익스포트 = 스케일 1.0 렌더
3. **`regionCode: String` 10자리 법정동코드** — 지금은 뒤 5자리 `00000`(구 단위), 후일 동 단위 확장 시 마이그레이션 0

```swift
@Model final class Page {
    var id: UUID = UUID()
    var regionCode: String = ""        // 법정동코드 10자리 (성동구 → 1120000000)
    var title: String = ""
    var createdAt: Date = Date()
    var layoutJSON: Data = Data()      // 레이어 전체. 내부 구조 자유 진화
    var photos: [PagePhoto]? = []
    @Attribute(.externalStorage) var renderedPNG: Data?   // 캐시
}

@Model final class PagePhoto {
    var id: UUID = UUID()
    @Attribute(.externalStorage) var data: Data = Data()  // 2000px 사본 → CKAsset
    var page: Page?
}
```

- SwiftData+CloudKit 제약: 모든 속성 기본값/optional 필수, `@Attribute(.unique)` 불가, 관계는 양방향 optional만
- 사진은 `.externalStorage` Data → CKAsset 자동 업로드 (8MB 레코드 제한 우회)

### 레이어 JSON 스키마 (v1)

```json
{
  "v": 1,
  "canvas": { "w": 1080, "h": 1920 },
  "background": { "preset": "kraft" },
  "layers": [
    { "type":"photo",   "assetId":"…", "x":540,"y":700,"scale":1.2,"rotation":-0.08,"z":0 },
    { "type":"text",    "string":"…","font":"serif","size":42,"color":"#3A3A3A","x":0,"y":0,"rotation":0,"z":1 },
    { "type":"stamp",   "date":"2026-07-29","style":"round","x":0,"y":0,"rotation":0.05,"z":2 },
    { "type":"drawing", "assetId":"…", "x":0,"y":0,"scale":1,"rotation":0,"z":3 }
  ]
}
```

- **날짜 도장 = 텍스트 레이어 프리셋** (별도 타입 아님, 렌더 스타일만 고정)
- **손그림 = 이미지 레이어** (`PKDrawing.image(from:scale:)`로 구워 `PagePhoto`로 저장 — ImageRenderer 누락 사고 방지)

## 5. 에디터

- 조작: 단일 선택. 탭 선택 / 빈 곳 탭 해제. 선택 레이어만 이동·핀치·회전, 우하단 코너 핸들로 크기+회전. 선택 시 삭제·앞으로·뒤로 버튼
- 회전 레이어 드래그 시 제스처 translation에 **역회전 행렬** 적용 필수 (스파이크 S2)
- 자동 임시저장: 변경 1.5초 디바운스 후 `layoutJSON` 갱신. 재실행 시 "이어서 할까요?"

## 6. 지도

- 서울 25구 GeoJSON → 정규화 좌표(0~1) SwiftUI `Path` 사전 변환
- 심도 6상태: 미방문(회색) / 1~2 / 3~4 / 5~9 / 10~19 / 20+
- 탭 히트테스트: `Path.contains(_:)`
- 경계 데이터 라이선스(공공누리 유형) 배포 전 확인 + 출처 표기

## 7. 익스포트

```
논리 캔버스 1080×1920 → ImageRenderer(scale:1.0) → JPEG 0.9 → 공유 시트
                          └─ [오버레이 슬롯: 비어있음] ← P1 비닐 자리
```

## 8. 에러 처리

| 상황 | 동작 |
|---|---|
| iCloud 미로그인/용량 초과 | 로컬 모드 자동 격하 + 설정에 상태 배너. 앱은 정상 동작 |
| 사진 로드 실패 | 해당 레이어 플레이스홀더, 나머지 정상 렌더 |
| 익스포트 실패 | 재시도 안내 (페이지 데이터는 이미 저장됨) |
| 저장공간 부족 | 사진 추가 시점 사전 체크 |

## 9. 테스트

- 레이어 JSON 인코딩→디코딩 라운드트립 (v1 호환성 회귀)
- 회전 상태 드래그 좌표 변환 단위 테스트
- 익스포트 결과 크기·비어있지 않음 검증
- CloudKit 동기화: 실기기 2대 수동 검증
