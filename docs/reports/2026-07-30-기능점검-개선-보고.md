## 1. 기능 인벤토리 (설계 기준)

### P0 (MVP 포함)

| 영역 | 기능 |
|---|---|
| 홈/지도 | 서울 25구 지도(SwiftUI Path), 방문 심도 6단계 색칠, 구 탭 → 필터 |
| 도감 | 구 카드 25장, 미방문 실루엣, 대표 썸네일 |
| 성취 | 구 정복률 + 카드 도감 + 방문 심도 (3중) |
| 에디터 | 1080×1920 논리 캔버스, 사진 ≤8장, 텍스트(폰트 4~5종·크기·색), 날짜 도장, 손그림 펜, 종이 배경 3~5종, 탭 선택+멀티터치+코너 핸들, z-order |
| 저장 | 자동 임시저장(1.5s)+복구, 삭제, 메타 수정 |
| 데이터 | SwiftData+CloudKit 동기화, 로컬 모드 자동 격하, 사진 2000px 사본 |
| 익스포트 | JPEG 1080×1920, iOS 공유 시트 |
| 뷰어 | 그리드 + 전체화면 스와이프 |
| 부가 | 검색·필터, Face ID 잠금, 빈 상태 안내 |

### P1 (보류) — 재편집, 마스킹테이프, 비닐 오버레이·바인더 링·사운드, 동(洞) 단위 확장
### 제외 — 위젯, 다크모드, GPS, 온보딩, 알림(당시 결정), 수익화, 서버·계정

## 2. UI/UX 개선 제안 (우선순위순)

1. **Undo 부재 (설계 구멍)** — 손그림+자유 배치 앱에 실행 취소가 전혀 없음.
   최소: 펜 모드 내 undo/redo + 레이어 삭제 시 스낵바 "실행 취소" + 뒤로가기 시 변경 파기 확인.
2. **재편집 P1 → P0 승격 권고** — 오타 하나에 페이지를 다시 만들어야 함. 데이터가 이미 레이어 JSON이라
   "저장된 페이지를 같은 에디터로 로드"만 붙이면 됨. 증분 공수 대비 체감 완성도 상승이 가장 큼.
3. **저장 완료 모먼트** — 저장 직후 결과 화면에서 ①비닐 씌워지는 연출(P1) ②해당 구 색이 진해지는 미니 지도 애니메이션
   ③공유 CTA를 한 화면에. 감정 피크에 성취·공유를 겹치는 게 리텐션 코어 루프.
4. **[+] 진입 마찰 축소** — 구 선택 시트에 '최근 구' 프리셀렉트 + 1탭 통과. 저장 단계에서 구 변경 가능하게.
5. **사진 다중 선택** — PHPicker로 최대 8장 일괄 선택 → 랜덤 미세 회전(-3°~3°)으로 자동 흩뿌리기 배치 후 조정 시작.
6. **뷰어 내 액션** — 전체화면 뷰어에 공유/메타 수정/삭제(/재편집) 배치. 그리드로 돌아가야만 조작 가능하면 답답함.
7. **첫 실행 보완** — 온보딩 제외 결정은 유지하되, 빈 캔버스에 '고스트 예시 페이지' 1장(탭하면 사라짐) 또는 3장 카드 1회.
8. **햅틱** — 도장 찍기, 구 색칠 단계 상승, 저장 완료에 haptic. 아날로그 질감 컨셉과 부합, 공수 미미.
9. **다크모드 미지원 명시** — `UIUserInterfaceStyle = Light` 고정하지 않으면 시스템 다크모드에서 색 깨짐.
10. **검색바 위치** — 홈 상단 고정 대신 '모음' 탭(아래 3탭 구조)으로 이동. 홈은 지도·성취에 집중.

## 3. 내비게이션 구조 제안 — 3탭

당시 결정은 "탭바 없이 단일 홈"이었으나, **알림·내 정보가 새로 들어오면 전제가 바뀜** → 3탭 권고.

```
탭1 「지도」   지도/도감 토글, 구 탭 → 구 상세(해당 구 페이지), 플로팅 [+]
탭2 「모음」   전체 페이지 그리드, 검색·필터, 전체화면 뷰어, 플로팅 [+]
탭3 「내 정보」 통계 + 성취 + 설정
```

- [+]는 지도·모음 탭 공통 우하단 플로팅 버튼 (탭바 중앙 돌출 버튼은 3탭에선 과함)
- 대안(단일 홈 유지)은 알림 설정·통계가 ⚙ 안으로 숨어 발견성이 나빠짐

### 내 정보 탭 구성 (계정 아님 — 서버리스 유지)

```
[통계 카드]  총 페이지 · 정복 구 n/25 · 이번 달 기록 · 연속 기록(스트릭)
[성취 요약]  도감 진행률, 가장 진한 구 Top3
[설정]
 ├ 알림       리마인더 토글·요일/시간, 추억 알림 토글
 ├ 보안       Face ID 잠금
 ├ 데이터     iCloud 동기화 상태·사용 용량, 백업 내보내기/가져오기(파일), 캐시 정리
 └ 정보       지도 데이터 출처(공공누리), 폰트 라이선스, 오픈소스,
              개인정보 처리방침, 문의(mailto), 앱 평가하기, 버전
```

- 닉네임/프로필 사진은 넣더라도 로컬 저장 필드로만 (계정 아님)
- **백업 내보내기/가져오기**(레이어 JSON+사진 zip → Files 앱): iCloud 미사용 유저의 유일한 안전망. P0.5 권고

## 4. 푸시 알림 설계 — 전부 로컬 알림

서버가 없으므로 원격 푸시(APNs 발송 서버) 불가. **`UNUserNotificationCenter` 로컬 알림으로 전부 해결** — 서버리스 유지, 오프라인 동작, 심사 부담 없음. (CloudKit 동기화용 silent push는 시스템이 내부 처리 — 유저 노출 없음)

| 알림 | 트리거 | 기본값 |
|---|---|---|
| 기록 리마인더 | 사용자 지정 요일·시간 (주 1회 권장) | off |
| 이어서 작성 | 임시저장 24시간 방치 시 1회 | on |
| 추억 소환 | "1년 전 오늘 ○○구에서" — 해당 날짜 페이지 존재 시 | on |
| 월간 결산 | 매월 말 "7월에 N개 구 수집" | on |

- **권한 요청 시점:** 첫 페이지 저장 완료 직후(감정 피크)에 프리프롬프트("기록을 이어가도록 도와드릴까요?") → 시스템 다이얼로그. 온보딩·첫 실행에서 묻지 않기.
- 알림 탭/인박스는 불필요 — iOS 알림 센터로 충분.
- 설정 > 알림에서 종류별 토글.

## 6. 권고 요약

1. 재편집 P0 승격 + Undo 추가 (완성도 대비 최대 효율)
2. 3탭 구조 전환 (지도/모음/내 정보) — 알림·통계·설정 자리 확보
3. 알림은 로컬 알림 4종, 권한 요청은 첫 저장 직후
4. 백업 내보내기 P0.5 (iCloud 미사용 유저 안전망)
5. 출시 준비물: 개인정보 처리방침 URL, 라이선스 고지, PrivacyInfo.xcprivacy, CloudKit 프로덕션 배포
6. 설계 문서 v2 갱신 필요 (3탭·알림 반영) — 사용자 승인 후
