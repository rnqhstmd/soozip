## 한 줄 소개

흰 캔버스 위에 사진·텍스트·도형을 자유롭게 배치해 한 장을 만들고, 그 장들을 사용자가 만든 모음집에 담는 서버리스 iOS 앱. 계정도 서버도 없습니다.

## 도메인

| 도메인 | 설명 | 상세 |
|--------|------|------|
| collection | 모음집 — 사용자가 만드는 최상위 수집 단위. 캐러셀·표지·정렬·삭제 | [상세](collection/README.md) |
| canvas | 캔버스 — 한 장의 생명주기. 규격·초안·저장·재편집·삭제 | [상세](canvas/README.md) |
| editor | 에디터 — 레이어 5종, 선택 UI, 스마트 가이드, 도구 7종 | [상세](editor/README.md) |
| media | 미디어 — 사진 임포트, 붙여넣기, 필터, 익스포트 | [상세](media/README.md) |
| sync | 저장·동기화 — SwiftData + CloudKit, 초안 파일 I/O, 백업 | [상세](sync/README.md) |
| profile | 내 정보 — 통계, 설정, 알림, 보안 | [상세](profile/README.md) |

## 도메인 경계

```
collection  모음집 CRUD · 표지 · 정렬
    │ 1:N
canvas      캔버스 생명주기 (초안 → 저장 → 재편집)
    │ 담는다
editor      레이어 5종 · 조작 · 배치
    │ 쓴다
media       사진 · 붙여넣기 · 필터 · 익스포트

sync        위 전부의 영속성 (SwiftData/CloudKit/Drafts)
profile     위 전부의 집계와 앱 설정
```

- **collection ↔ canvas**: 캔버스는 정확히 하나의 모음집에 속한다. 모음집 없는 캔버스는 없다.
- **canvas ↔ editor**: canvas는 "언제 저장되는가", editor는 "무엇을 어떻게 배치하는가"를 맡는다. 저장 트랜잭션은 canvas 소관.
- **editor ↔ media**: editor는 레이어의 위치·크기·순서를, media는 그 레이어에 들어갈 픽셀을 다룬다.
- **sync**: 다른 도메인이 부르는 저장소. 도메인 규칙을 담지 않는다.
