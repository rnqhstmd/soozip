# collection 용어 사전

| 용어 | 설명 |
|------|------|
| 모음집 (Collection) | 사용자가 만드는 수집 단위. 이름·생성순·대표 캔버스를 가진다 |
| 캐러셀 | 첫 화면의 가로 스크롤 모음집 목록. 맨 좌측에 [+] 카드가 고정된다 |
| 전체 보기 | 캐러셀이 길어졌을 때 쓰는 모음집 그리드 화면 |
| 표지 | 모음집 카드에 그려지는 대표 캔버스의 `renderedPNG` |
| 대표 캔버스 | 표지로 쓰이는 캔버스. `coverCanvasID`로 지정하며, 비면 가장 최근 캔버스가 쓰인다 |
| `sortIndex` | 모음집 정렬 순서. 생성순이 기본이고 사용자가 드래그로 바꾸면 고정된다 |
| 승계 | 대표 캔버스가 삭제되거나 다른 모음집으로 옮겨질 때 다음 캔버스가 표지를 물려받는 것 |
| cascade 삭제 | 모음집을 지우면 그 안의 캔버스와 사진이 함께 지워지는 것 |
