# media 용어 사전

| 용어 | 설명 |
|------|------|
| 톤 필터 | 파스텔 12색에 대응하는 색조 매핑 프리셋. 강도 0~100% |
| 계단식 배치 | PHPicker로 여러 장을 넣을 때 겹치지 않게 조금씩 어긋나게 놓는 것 |
| 2000px 사본 | 원본 사진을 긴 변 2000px로 줄인 저장본. CloudKit에는 CKAsset으로 올라간다 |
| `assetId` | 레이어가 참조하는 사진 식별자. **복제된 사진 레이어들은 같은 `assetId`를 공유한다** |
| 고아 `CanvasPhoto` | 어떤 레이어도 참조하지 않는 사진 레코드. 저장 시점에 정리한다 |
| `UIPasteControl` | iOS 16+의 붙여넣기 버튼. 사용자가 누른 것 자체를 동의로 간주해 허용 프롬프트가 뜨지 않는다 |
| 피사체 들어올리기 | iOS 사진 앱 기본 기능. 사진을 길게 눌러 피사체만 배경에서 분리·복사한다. **우리 앱의 누끼 대체 경로** |
| 알파 트림 | 붙여넣은 투명 이미지를 알파 바운딩 박스로 한 번 크롭하는 것. 핸들이 투명 여백에 뜨는 것을 막는다 |
| 사본 포맷 규칙 | 불투명하지 않은 픽셀이 있으면 PNG, 없으면 JPEG 0.9. 전부 JPEG면 투명도가 날아간다 |
| `opaque = false` | `UIGraphicsImageRendererFormat`의 설정. **투명 이미지 리사이즈 시 반드시 꺼야 한다** — `true`면 그 순간 투명 영역이 배경색으로 구워져 이후 PNG로 저장해도 되살릴 수 없다 |
| 투명 픽셀 판정 | 알파 채널 유무 확인 후 64×64 다운샘플에서 실제 투명 픽셀을 스캔하는 2단계. 채널만 보면 스크린샷까지 PNG가 되고, 전수 스캔은 비싸다 |
| `renderedPNG` | 캔버스 전체를 렌더한 결과. 그리드·표지·썸네일용 캐시 |
| 익스포트 | 논리 캔버스를 `ImageRenderer(scale: 1.0)` → JPEG 0.9로 굽는 것 |
| 사진에 저장 | `PHPhotoLibrary`로 사진 앱에 직접 저장. P0의 유일한 내보내기 |
| 스토리 딥링크 | `instagram-stories://share`. 인스타그램 스토리에 직접 올리는 공식 경로 (P1) |
| ~~누끼~~ | **P0에서 제외됨.** 사진 배경 제거. 제외 근거는 README 참조 |
