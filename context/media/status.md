# media 구현 추적

> v4 설계서의 P0 요구사항별 구현 상태를 추적합니다.
>
> **최종 갱신: 2026-08-22 — PR #17(EDITOR-9)까지 대조했고 이 도메인은 변경 없음.**
> 내용이 마지막으로 **바뀐** 시점은 2026-08-12(PR #9 / EDITOR-3)이다. 그 이후 머지된 PR #11~#17은 전부 editor 도메인이라 이 도메인의 항목에 닿지 않았다.
> **미머지 PR #18(EDITOR-10 제스처 라우팅 + 클램프 게이트)도 함께 대조했고 이 도메인 참조 0건이다** — 머지 시 재대조 불필요.
> ("대조"와 "반영"을 구분해 적는다 — 확인했는데 바뀔 것이 없었던 것과 잊힌 것은 다르다.)
> **이 도메인은 실질적으로 미착수다** — 모델과 승격 경로만 있고 픽셀을 다루는
> 코드(`UIImage`·`PHPicker`·`ImageRenderer`)는 아직 한 줄도 없다.
> v1 범위는 `MEDIA-1~6`으로 좁혀져 있다(필터·누끼는 제외).
