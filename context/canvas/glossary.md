# canvas 용어 사전

| 용어 | 설명 |
|------|------|
| 캔버스 (Canvas) | 사용자가 만드는 한 장 |
| 게시물 프리셋 | 1080×1350 (4:5). 인스타그램 피드용 |
| 스토리 프리셋 | 1080×1920 (9:16). 인스타그램 스토리용 |
| `aspect` | 비율을 나타내는 Int 열거값. 0 = 4:5, 1 = 9:16 |
| 초안 (Draft) | 저장 전 편집 중인 캔버스. `Application Support/Drafts/<uuid>/`에 `layout.json` + 사진 사본으로 존재 |
| 승격 (Promotion) | 초안이 저장 확정되어 `Canvas` 레코드가 되는 것 |
| 자동 임시저장 | 변경 후 1.5초 디바운스로 `layout.json`을 덮어쓰는 것. 명시적 버튼은 없다 |
| 3지선다 | 에디터 [뒤로] 시 묻는 `계속 편집` / `임시저장하고 나가기` / `삭제하고 나가기` |
| `renderedPNG` | 캔버스를 1080×H로 렌더한 결과 이미지. 그리드·표지·썸네일에 쓰이는 캐시이며 재편집 시 재생성된다 |
| 메타 수정 | 제목·날짜·소속 모음집만 바꾸는 것. 에디터를 거치지 않으므로 `renderedPNG` 재생성이 필요 없다 |
| 고아 초안 | 크래시 등으로 남은, 소속 모음집이 없거나 7일 이상 방치된 `Drafts/` 폴더 |
