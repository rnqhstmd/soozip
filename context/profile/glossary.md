# profile 용어 사전

| 용어 | 설명 |
|------|------|
| 연속 기록 | 캔버스를 1장 이상 저장한 **날**이 연속된 일수(저장 건수가 아니라 날 수). `createdAt` 기준이며 모음집을 가로지른다. **기준 시각 `now`를 받아 계산한다** — ①`now`의 오늘보다 미래인 기록 날짜는 제외 ②가장 최근 저장일이 오늘 또는 어제면 거기서 거슬러 센다 ③그보다 오래됐으면 0 |
| 가장 많이 담은 모음집 | 캔버스 수가 최다인 모음집 이름 + 개수. **동수면 먼저 만든 쪽**(BR-8) |
| 프리프롬프트 | 시스템 권한 다이얼로그 앞에 앱이 직접 띄우는 설명 화면. 거부 기회를 낭비하지 않기 위한 장치 |
| 기록 리마인더 | 사용자가 지정한 요일·시간에 오는 알림. 기본 off |
| 이어서 작성 | 초안이 24시간 방치되면 1회 오는 알림. 기본 on |
| 추억 소환 | "1년 전 오늘 만든 캔버스" 알림. 기본 on |
| 월간 결산 | 매월 말 "이번 달 N장을 모았어요" 알림. 기본 on |
| 백그라운드 커버 | Face ID 잠금 시 앱 스위처 스냅샷을 가리는 화면. `scenePhase == .inactive`에서 덮는다 |
| 심사 4.5.4 | 앱 기능이 푸시 알림 허용에 의존해서는 안 된다는 App Store 심사 규정 |
| 심사 2.1 | 앱 완성도 규정. 빈 상태 화면이 미완성으로 읽히면 걸린다 |
| 유예 1일 | 오늘 아직 저장하지 않았다는 이유만으로 연속이 끊기지 않는 규칙. 어제까지다 — 이틀 이상 비면 0 |
| 기준 시각 주입 | 통계가 `now`·`Calendar`를 파라미터로 받는 것. 실행 시각과 CI 타임존에 결과가 흔들리지 않게 한다 |
