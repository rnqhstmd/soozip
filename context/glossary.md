# 공통 용어 사전

> 도메인을 가리지 않고 프로젝트 전체에서 쓰이는 용어입니다.
> 도메인별 용어는 `context/{도메인}/glossary.md`를 참조하세요.

| 용어 | 설명 |
|------|------|
| soozip | 앱 이름. **전부 소문자**가 정식 표기. "수집"에서 왔다. 코드 식별자와 Xcode Product Name은 `Soozip` |
| 모음집 (Collection) | 사용자가 만드는 수집 단위. 캔버스를 담는다 |
| 캔버스 (Canvas) | 사용자가 만드는 한 장. 4:5 또는 9:16 |
| 레이어 (Layer) | 캔버스 위에 올라가는 요소. `photo` · `text` · `shape` · `stamp` · `drawing` 5종 |
| 초안 (Draft) | 저장 전 편집 중인 캔버스. SwiftData가 아닌 로컬 `Drafts/` 폴더에 산다 |
| 승격 (Promotion) | 초안이 저장 확정되어 `Canvas` 레코드가 되는 것 |
| 논리좌표 | 기기와 무관한 캔버스 내부 좌표계. 폭 1080 고정, 높이 1350 또는 1920 |
| `layoutJSON` | 배경과 레이어 배열 전체를 담은 한 덩어리 JSON. CloudKit 스키마를 건드리지 않는 확장 통로 |
| 파스텔 12색 | 명도·채도를 고정하고 색상만 30° 등간격으로 나눈 앱 상수 팔레트 |
| 복제 | 선택 레이어를 +40,+40 오프셋에 그대로 복사하는 것. 전 타입 지원 |
| 붙여넣기 | 다른 앱에서 복사한 이미지를 `UIPasteControl`로 캔버스에 얹는 것 |
| 스마트 가이드 | 드래그·리사이즈 중 정렬·균등 간격·크기 일치를 감지해 가이드선과 햅틱을 주는 기능 |
| z-order | 레이어 겹침 순서. 맨 앞으로 / 앞으로 / 뒤로 / 맨 뒤로 4종으로 조작 |
| 작업 영역 | 캔버스의 2배 범위. 레이어가 캔버스 밖으로 나갈 수 있는 한계 |
| 고스트 | 캔버스 밖으로 나간 레이어를 에디터에서 30% 불투명도로 표시한 것 |
| fit | 캔버스가 화면에 꽉 차게 들어간 배율. 줌 100%의 기준 |
| P0 / P0.5 / P1 / P2 | 우선순위. P0 = MVP 필수, P1 = 출시 후, P2 = 그 이후 |
| 스파이크 (Spike) | 구현 전 기술 검증. S1~S4 |
| OFL | SIL Open Font License. 앱 번들 임베딩을 명시적으로 허용하는 폰트 라이선스 |
| additive-only | CloudKit 스키마를 첫 심사 후에는 추가만 가능하고 변경·삭제할 수 없는 제약 |
| 로컬 모드 | iCloud 미로그인·용량 초과 시 동기화 없이 기기 안에서만 동작하는 격하 상태 |
